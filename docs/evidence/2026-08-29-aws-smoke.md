# Live smoke — first AWS deployment (2026-08-29 03:29 UTC)

Account: owner's AWS account, us-east-1. Deployed by hand with `cdk deploy --all -c imageTag=<git sha>`
from a workstation (the GitHub Actions pipeline was not exercised — the repository was not yet published).

Image: ECR `agentops-gate:0275a655…` (linux/amd64, built from the host-built jar with the Dockerfile's
runtime stage; the emulated amd64 Maven build stage crashes under QEMU on Apple Silicon).

Stacks: Budget (created first), Network (2 AZs, public subnets only, no NAT), Queue (SQS + DLQ),
Bucket (S3, lifecycle rule), Data (RDS db.t4g.micro single-AZ, two Secrets Manager secrets),
Service (ECS Fargate 0.25 vCPU / 0.5 GB, public IP, SG 8080/tcp only, task role scoped to one queue,
one bucket, two secrets; log group; 5xx metric filter + alarm).

First Service stack deploy tripped the ECS deployment circuit breaker and rolled back; the rollback
deleted the log group, so the root cause was not captured. The second deploy (identical template
except `circuitBreaker.rollback=false` for diagnosis) started cleanly in ~15 s; no task ever stopped.
Rollback is re-enabled in code.
